# DIFF-Geo

This folder provides a reference implementation of paper -- Geolocating Unreachable Target IPs: A Blind Spot in Cyberattack Traceback(IEEE Transactions on Dependable and Secure Computing).


## Basic Usage

### Requirements

The code was tested with `python 3.10.14`, `pytorch 2.2.0+cu118`,  `cudatoolkit 11.8.0`, and `cudnn 8.7.0`. Install the dependencies via [Anaconda](https://www.anaconda.com/):

```shell
# create virtual environment
conda create --name DIFF_Geo python=3.10.14

# activate environment
conda activate DIFF_Geo

# install pytorch & cudatoolkit & dgl
conda install pytorch torchvision torchaudio dgl cudatoolkit=11.8 -c pytorch -c conda-forge
# install other requirements
conda install numpy pandas
pip install scikit-learn
```

### Run the code

```shell
# Open the "DIFF-Geo" folder
cd DIFF-Geo

#DIFF-Geo consists of three modules: Exten-C, DIFF-Gen, and DA-GNN. In this project, experiments are conducted on three datasets: Osaka, Hong Kong, and Los Angeles. We use the Osaka dataset as an example.

#Perform network measurements on the landmarks in the datasets to obtain network measurement data.
cd Datasets
cd Osaka
#new_Osaka_acc.csv is the landmark set, and network measurements are performed on this landmark set. Osaka.txt.txt contains the example network measurement results.

#Perform C-segment expansion on the unreachable IPs in the network measurement data, and conduct network measurements on the expanded IPs. The JSON files in the folder are examples of the C-segment expansion results.
cd ExtenC-Data

#Concatenate the original network measurement data with the JSON files generated by C-segment expansion. For example, concatenate Osaka.txt.txt and Osaka_C.json to generate Osaka_final.txt.txt.

#Place the concatenated file and the original network measurement file into the DIFF-Gen folder.

#run the module DIFF-Gen
python 1_DIFF_Gen_v3_10.py
python 2_gen_final.py

#Perform data preprocessing to generate feature files.
cd Preprocess
#Place data.csv, data_train.csv, data_val.csv, data_test.csv, and new_Osaka_acc.csv from the Dataset into the Preprocess folder. Place Osaka_completed_final_final.txt generated by DIFF-Gen into the hk_to_OS_trace folder.
python get_txt.py
python preprocess1.py
python preprocess2.py
python preprocess3.py
python preprocess4.py

#Place the original network measurement file into DA-GNN, and place the feature files generated by data preprocessing into the data_0201 folder in the Algorithm folder.
cd DA-GNN
cd Algorithm

# run the module DA-GNN
python mpnn_geo_v19_dann.py  --edge_hidden_size 16 --gpuid 0 --num_step_message_passing 2  --domain_dp 0.1

```

## The description of hyperparameters used in mpnn_geo_v19_dann.py

| Hyperparameter          | Description                                           |
| :-----------------------| ----------------------------------------------------- |
| edge_hidden_size        | the edge embedding dimension                          |
| num_step_message_passing| the number of MPNN layers                             |
| domain_dp               | domain random dropout rate                            |
| gpuid                   | the GPU index                                         |

## Dataset Information

The "Datasets" folder contains three subfolders corresponding to three real-world street-level IP geolocation datasets collected from Osaka City, HongKong and LosAngeles. There are six files in each folder:

- data.csv    *# All landmarks for Osaka/HongKong/LosAngeles* 
- data_train.csv    *# Training set for Osaka/HongKong/LosAngeles*
- data_val.csv   *# Validation set for Osaka/HongKong/LosAngeles*
- data_test.csv   *# Testing set for Osaka/HongKong/LosAngeles*
- new_Osaka_acc.csv   *# All landmarks for Osaka/HongKong/LosAngeles*
- Osaka.txt.txt   *# Original network measurement data*
